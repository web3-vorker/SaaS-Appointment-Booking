# Developer Bot - Документация

## Описание

Developer Bot - это Telegram бот для управления бизнесами, подключенными к SaaS сервису записи клиентов.

## Структура проекта

```
dev_bot/
├── config/
│   └── config.py          # Конфигурация бота
├── handlers/
│   └── dev_handlers.py    # Обработчики команд и callback'ов
├── keyboards/
│   └── dev_keyboards.py   # Inline клавиатуры
├── states/
│   └── dev_states.py      # FSM состояния
├── utils/
│   └── api.py             # API клиент для dev endpoints
├── init_bot.py            # Инициализация бота
└── bot.py                 # Точка входа
```

## Переменные окружения

Добавьте в `.env` файл:

```env
# Developer Bot
DEV_BOT_TOKEN=your_dev_bot_token_here
DEVELOPER_KEY=your_developer_key_here
```

## Функционал

### ✅ Реализовано:

1. **Управление бизнесами:**
   - Просмотр списка всех бизнесов
   - Создание нового бизнеса
   - Удаление бизнеса

2. **Управление сотрудниками:**
   - Добавление сотрудника к бизнесу

3. **Управление услугами:**
   - Добавление услуги к бизнесу

### 📋 Основные команды:

- `/start` - Открыть главное меню developer панели

### 🎯 Главное меню:

- 📋 Список бизнесов
- ➕ Создать бизнес
- 👥 Управление сотрудниками
- 🛠️ Управление услугами
- 🔗 Привязка услуг
- 📅 Управление графиком

## Запуск

```bash
python dev_bot/bot.py
```

## Процесс создания бизнеса

1. Нажать "➕ Создать бизнес"
2. Ввести название бизнеса
3. Ввести время начала работы (HH:MM)
4. Ввести время окончания работы (HH:MM)
5. Ввести Telegram ID владельца
6. Ввести токен Telegram бота для бизнеса
7. Получить API ключ (сохранить!)

## Процесс добавления сотрудника

1. Нажать "👥 Управление сотрудниками"
2. Нажать "➕ Добавить сотрудника"
3. Выбрать бизнес
4. Ввести имя сотрудника
5. Ввести должность

## Процесс добавления услуги

1. Нажать "🛠️ Управление услугами"
2. Нажать "➕ Добавить услугу"
3. Выбрать бизнес
4. Ввести название услуги
5. Ввести цену (в рублях)
6. Ввести длительность (в минутах)
7. Ввести описание (или '-' чтобы пропустить)

## API клиент

Класс `DevAPI` в `utils/api.py` предоставляет методы для работы с developer endpoints:

- `get_all_businesses()` - получить все бизнесы
- `create_business()` - создать бизнес
- `delete_business()` - удалить бизнес
- `create_staff()` - создать сотрудника
- `delete_staff()` - удалить сотрудника
- `create_service()` - создать услугу
- `delete_service()` - удалить услугу
- `assign_service_to_staff()` - привязать услугу к сотруднику
- `update_schedule()` - обновить график работы
- `create_schedule_exception()` - создать исключение в графике
- `get_schedule_exceptions()` - получить исключения
- `delete_schedule_exception()` - удалить исключение

## Примечания

- Все запросы к API используют `DEVELOPER_KEY` для аутентификации
- FSM (Finite State Machine) используется для многошаговых диалогов
- Inline клавиатуры обеспечивают удобную навигацию
- Код написан просто и понятно, следуя стилю основного проекта
